## Lune — Sitio Web para Panadería Artesanal 🍞✨

## 📖Descripción del Proyecto
Lune es una plataforma web desarrollada para una panadería artesanal, orientada a ofrecer una experiencia visual moderna y una gestión dinámica de productos mediante un panel de administración.

El sitio cuenta con una sección institucional para presentar la identidad de la marca, información sobre la panadería y sus productos, además de una carta digital administrable que permite actualizar contenido sin modificar directamente el código fuente.

## ⚙️El sistema administrativo permite:
-Agregar productos.
-Editar productos existentes.
-Eliminar productos.
-Actualizar precios.
-Modificar descripciones.
-Cambiar imágenes.
-Administrar categorías.

## 🔄Gestión Dinámica
Los cambios realizados desde el panel se reflejan automáticamente en el sitio web.

## 🔐Autenticación
-Acceso restringido mediante login.
-Protección del panel administrativo.
